## 2026-05-21 — Messenger teammates & tasks

### Added

- Messenger teammate loops in group chats — async subagents and curator signals
- `/connect` pairing codes with per-channel autonomy controls
- Copilot persona overlays for messenger teammates tied to live workspace context
- Task vocabulary — issues renamed to **tasks** across the product

### Improved

- Task list updates and websocket cache reliability on the board
- CLI, Docker, and desktop install paths aligned
