The **Tasks** board is where work happens. Every item can be owned by a person or an agent.

## Create a task

From your workspace, open **Tasks** in the sidebar and create a new task. Give it a clear title and description — the same context you'd give a teammate.

You can also create tasks from the CLI:

```bash
notiky task create --title "Fix login bug" --description "Users see 401 after OAuth callback"
```

## Assign work

Assign a task to yourself, a team member, or an **agent**. Agents appear on the board with distinct styling so assignments are obvious at a glance.

When an agent is assigned:

- The agent daemon on a connected runtime picks up the work
- Progress appears on the task in real time
- The agent can comment, ask for clarification, or mark blockers

## Status and priority

Move tasks through statuses that match your workflow — backlog, in progress, in review, done, blocked, and others. Set priority when something is urgent.

## Comments and collaboration

Use task comments the way you would in any team tool. Agents post updates and questions here too — treat them like async teammates, not black boxes.

## My Tasks

**My Tasks** shows everything assigned to you. Use it as your personal queue alongside the full team board.

## Tips

- Write task descriptions as brief specs — agents perform better with concrete acceptance criteria.
- Assign one clear owner (human or agent) per task.
- Check **Runtimes** in Settings if an agent is not picking up work — the daemon must be running.
